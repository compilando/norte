# Indexed search sub-project 1: `norte-index` + FTS5 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `norte-index` crate providing a SQLite FTS5 name/metadata index, wired through the protocol, engine, daemon, and CLI so `norte index build <path>` indexes a subtree and `norte index query <path> <text>` returns fast indexed name matches.

**Architecture:** `Index` wraps a SQLite DB (external-content FTS5 kept in sync by triggers): a `files` table holds raw path/name BLOBs (regla-1 authority) plus lossy-UTF-8 display columns for tokenization; `build` upserts a subtree by `(root_id, path)` and sweeps vanished rows; `query` runs FTS5 `MATCH`. The engine holds an `Index`, exposes `index_build_as` as a cancelable policy-gated Task walking `Provider::list`, and `index_query`.

**Tech Stack:** `sqlx` 0.8 SQLite (FTS5 confirmed in the bundled build), the `SqliteJournal` open pattern, `run_walk`'s BFS+confine+cancellation shape.

**Reference:** `docs/superpowers/specs/2026-07-23-index-fts5-design.md`.

//! `norte-index`: índice SQLite FTS5 de nombres/metadata (spec §9, ADR 0034).
//! Los BYTES crudos de path/name son la AUTORIDAD (BLOB, regla 1); una vista
//! UTF-8 lossy alimenta FTS5 para el matching. Índice de solo-lectura tras
//! `build`; single-writer (dueño = daemon), como el journal.
#![warn(missing_docs)]

use std::path::Path;

use sqlx::Row;
use sqlx::sqlite::{SqlitePool, SqlitePoolOptions, SqliteConnectOptions, SqliteJournalMode};

/// Error del índice.
#[derive(Debug, thiserror::Error)]
pub enum IndexError {
    /// Fallo de SQLite (abrir, migrar, consultar).
    #[error("sqlite: {0}")]
    Sqlite(#[from] sqlx::Error),
}

/// El índice: una conexión SQLite (WAL) con el schema `files` + `files_fts`.
#[derive(Debug, Clone)]
pub struct Index {
    pool: SqlitePool,
}

impl Index {
    /// Abre/crea el índice en `path` (WAL, schema idempotente).
    ///
    /// # Errors
    /// [`IndexError::Sqlite`] si no se puede abrir o migrar.
    pub async fn open(path: &Path) -> Result<Self, IndexError> {
        let opts = SqliteConnectOptions::new()
            .filename(path)
            .create_if_missing(true)
            .journal_mode(SqliteJournalMode::Wal);
        Self::from_options(opts).await
    }

    /// Índice en memoria (tests).
    ///
    /// # Errors
    /// [`IndexError::Sqlite`] si la migración falla.
    pub async fn open_memory() -> Result<Self, IndexError> {
        // `:memory:` con pool de 1 conexión (cada conexión tendría su propia BD).
        let opts = SqliteConnectOptions::new().in_memory(true);
        let pool = SqlitePoolOptions::new().max_connections(1).connect_with(opts).await?;
        let idx = Self { pool };
        idx.migrate().await?;
        Ok(idx)
    }

    async fn from_options(opts: SqliteConnectOptions) -> Result<Self, IndexError> {
        let pool = SqlitePoolOptions::new().connect_with(opts).await?;
        let idx = Self { pool };
        idx.migrate().await?;
        Ok(idx)
    }

    async fn migrate(&self) -> Result<(), IndexError> {
        // Tabla de autoridad (bytes crudos) + columnas display para FTS5.
        sqlx::query(
            "CREATE TABLE IF NOT EXISTS files (
                 id INTEGER PRIMARY KEY,
                 root_id INTEGER NOT NULL,
                 path BLOB NOT NULL,
                 name BLOB NOT NULL,
                 name_display TEXT NOT NULL,
                 path_display TEXT NOT NULL,
                 kind INTEGER NOT NULL,
                 size INTEGER,
                 mtime_ms INTEGER,
                 last_seen_build INTEGER NOT NULL,
                 UNIQUE(root_id, path)
             )",
        )
        .execute(&self.pool)
        .await?;
        // FTS5 external-content sobre `files`; los triggers la mantienen en sync.
        sqlx::query(
            "CREATE VIRTUAL TABLE IF NOT EXISTS files_fts USING fts5(
                 name_display, path_display, content='files', content_rowid='id'
             )",
        )
        .execute(&self.pool)
        .await?;
        sqlx::query(
            "CREATE TRIGGER IF NOT EXISTS files_ai AFTER INSERT ON files BEGIN
                 INSERT INTO files_fts(rowid, name_display, path_display)
                 VALUES (new.id, new.name_display, new.path_display);
             END",
        )
        .execute(&self.pool)
        .await?;
        sqlx::query(
            "CREATE TRIGGER IF NOT EXISTS files_ad AFTER DELETE ON files BEGIN
                 INSERT INTO files_fts(files_fts, rowid, name_display, path_display)
                 VALUES ('delete', old.id, old.name_display, old.path_display);
             END",
        )
        .execute(&self.pool)
        .await?;
        Ok(())
    }
}

use norte_proto::{EntryKind, VPath};
use tokio_util::sync::CancellationToken;

/// Una entrada a indexar (proyección de `norte_vfs::Entry` sin el mtime opcional
/// del stream). `path` completo (bytes crudos, regla 1).
#[derive(Debug, Clone)]
pub struct IndexEntry {
    /// Path completo bajo el root.
    pub path: VPath,
    /// Tipo de entrada.
    pub kind: EntryKind,
    /// Tamaño (`None` para dirs).
    pub size: Option<u64>,
    /// mtime en ms desde epoch (`None` si desconocido).
    pub mtime_ms: Option<i64>,
}

/// Resumen de un `build`.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub struct BuildReport {
    /// Entradas insertadas o actualizadas.
    pub indexed: u64,
    /// Filas barridas (paths que ya no existen), 0 si se canceló.
    pub removed: u64,
}

/// Id estable del root a partir de su forma canónica (`scheme://authority` + base).
fn root_id(root: &VPath) -> i64 {
    // FNV-1a de 64 bits sobre el display canónico del root; estable entre procesos.
    let s = root.display_lossy();
    let mut h: u64 = 0xcbf2_9ce4_8422_2325;
    for b in s.as_bytes() {
        h ^= u64::from(*b);
        h = h.wrapping_mul(0x0000_0100_0000_01b3);
    }
    h as i64
}

impl Index {
    /// (Re)indexa `root` con `entries`: upsert por `(root_id, path)`, luego barre
    /// las filas de ese root NO vistas en este build. Cancelable: si el token se
    /// dispara, se saltan tanto el resto de entradas como el BARRIDO (las filas ya
    /// insertadas persisten — superset coherente, jamás una poda equivocada).
    ///
    /// # Errors
    /// [`IndexError::Sqlite`].
    pub async fn build(
        &self,
        root: &VPath,
        entries: impl IntoIterator<Item = IndexEntry>,
        cancel: &CancellationToken,
    ) -> Result<BuildReport, IndexError> {
        let rid = root_id(root);
        // build_id monótono para este root: MAX previo + 1.
        let prev: i64 = sqlx::query_scalar("SELECT COALESCE(MAX(last_seen_build),0) FROM files WHERE root_id = ?")
            .bind(rid)
            .fetch_one(&self.pool)
            .await?;
        let build_id = prev + 1;
        let mut indexed = 0u64;
        let mut cancelled = false;
        // Commit por lotes para acotar la memoria del WAL y para que una
        // cancelación deje persistido lo ya hecho.
        let mut tx = self.pool.begin().await?;
        let mut in_batch = 0u32;
        for e in entries {
            if cancel.is_cancelled() {
                cancelled = true;
                break;
            }
            let path_bytes = e.path.to_bytes(); // ver nota de serialización abajo
            let name_bytes = e
                .path
                .file_name()
                .map(|s| s.as_bytes().to_vec())
                .unwrap_or_default();
            let name_display = String::from_utf8_lossy(&name_bytes).into_owned();
            let path_display = e.path.display_lossy();
            sqlx::query(
                "INSERT INTO files
                     (root_id, path, name, name_display, path_display, kind, size, mtime_ms, last_seen_build)
                 VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)
                 ON CONFLICT(root_id, path) DO UPDATE SET
                     kind = excluded.kind, size = excluded.size,
                     mtime_ms = excluded.mtime_ms, last_seen_build = excluded.last_seen_build",
            )
            .bind(rid)
            .bind(&path_bytes)
            .bind(&name_bytes)
            .bind(&name_display)
            .bind(&path_display)
            .bind(kind_to_i64(e.kind))
            .bind(e.size.map(|v| v as i64))
            .bind(e.mtime_ms)
            .bind(build_id)
            .execute(&mut *tx)
            .await?;
            indexed += 1;
            in_batch += 1;
            if in_batch >= 512 {
                tx.commit().await?;
                tx = self.pool.begin().await?;
                in_batch = 0;
            }
        }
        tx.commit().await?;
        let removed = if cancelled {
            0
        } else {
            let res = sqlx::query("DELETE FROM files WHERE root_id = ? AND last_seen_build != ?")
                .bind(rid)
                .bind(build_id)
                .execute(&self.pool)
                .await?;
            res.rows_affected()
        };
        Ok(BuildReport { indexed, removed })
    }
}

/// Discriminante estable de `EntryKind` para la columna `kind`.
fn kind_to_i64(k: EntryKind) -> i64 {
    match k {
        EntryKind::File => 0,
        EntryKind::Dir => 1,
        EntryKind::Symlink => 2,
        EntryKind::Other => 3,
    }
}

fn kind_from_i64(v: i64) -> EntryKind {
    match v {
        1 => EntryKind::Dir,
        2 => EntryKind::Symlink,
        3 => EntryKind::Other,
        _ => EntryKind::File,
    }
}

```rust
/// Un resultado de `query`: el path (bytes crudos reconstruidos) + metadata.
#[derive(Debug, Clone)]
pub struct IndexHit {
    /// Path completo (bytes exactos del índice de autoridad).
    pub path: VPath,
    /// Tipo.
    pub kind: EntryKind,
    /// Tamaño (`None` para dirs).
    pub size: Option<u64>,
    /// mtime ms (`None` si desconocido).
    pub mtime_ms: Option<i64>,
}

impl Index {
    /// Busca en el índice de `root` por `text` (FTS5 MATCH, prefijo-AND de los
    /// términos), rankeado por bm25, hasta `limit` hits. El `text` del usuario se
    /// SANEA a una query FTS5 válida (no se pasa crudo — evita errores de sintaxis
    /// por `*`/`"`/`:` del usuario): cada token whitespace se emite como prefijo
    /// citado. Query vacía tras sanear → sin hits.
    ///
    /// # Errors
    /// [`IndexError::Sqlite`].
    pub async fn query(&self, root: &VPath, text: &str, limit: u32) -> Result<Vec<IndexHit>, IndexError> {
        let rid = root_id(root);
        let Some(fts) = sanitize_fts_query(text) else {
            return Ok(Vec::new());
        };
        let rows = sqlx::query(
            "SELECT f.path AS path, f.kind AS kind, f.size AS size, f.mtime_ms AS mtime_ms
             FROM files_fts fts JOIN files f ON f.id = fts.rowid
             WHERE fts.files_fts MATCH ?1 AND f.root_id = ?2
             ORDER BY bm25(fts.files_fts) LIMIT ?3",
        )
        .bind(&fts)
        .bind(rid)
        .bind(i64::from(limit))
        .fetch_all(&self.pool)
        .await?;
        let mut hits = Vec::with_capacity(rows.len());
        for r in rows {
            let path_bytes: Vec<u8> = r.get("path");
            // Reconstruye el VPath desde los bytes de autoridad (mismo encoding que
            // usó `build`). Un byte corrupto en la BD sería un fallo interno; se
            // salta (no debería pasar — lo escribió `build` con to_bytes).
            let Some(path) = vpath_from_bytes(&path_bytes) else { continue };
            hits.push(IndexHit {
                path,
                kind: kind_from_i64(r.get::<i64, _>("kind")),
                size: r.get::<Option<i64>, _>("size").map(|v| v as u64),
                mtime_ms: r.get("mtime_ms"),
            });
        }
        Ok(hits)
    }
}

/// Convierte el texto libre del usuario en una query FTS5 SEGURA: separa por
/// whitespace, descarta caracteres especiales de FTS5 de cada token, y emite
/// cada token no vacío como prefijo citado (`"tok"*`), unidos por espacio (AND).
/// `None` si no queda ningún token.
fn sanitize_fts_query(text: &str) -> Option<String> {
    let mut parts = Vec::new();
    for tok in text.split_whitespace() {
        // Deja solo alfanum + guiones/puntos/underscore (seguros como término).
        let cleaned: String = tok
            .chars()
            .filter(|c| c.is_alphanumeric() || matches!(c, '-' | '_' | '.'))
            .collect();
        if !cleaned.is_empty() {
            parts.push(format!("\"{cleaned}\"*"));
        }
    }
    if parts.is_empty() { None } else { Some(parts.join(" ")) }
}
```

    ///
    /// # Errors
    /// Policy denegada, provider ausente, o error del índice/walk.
    pub async fn index_build_as(
        &self,
        root: VPath,
        actor: crate::journal::Actor,
    ) -> Result<TaskHandle, Error> {
        let index = self.index.clone().ok_or(Error::Unsupported)?;
        // Gate PRE-efecto por actor (mismo patrón que copy/search).
        self.policy_gate(&actor, &[&root])?; // usar el helper real del engine
        let provider = self.provider_for(&root).await?;
        let key = root.scheme().to_owned();
        let handle = self.sched.submit(
            &key,
            TaskKind::Index,
            Priority::Normal,
            actor,
            Box::new(move |ctx| {
                Box::pin(async move {
                    let entries = walk_for_index(provider, root.clone(), &ctx).await?;
                    let report = index
                        .build(&root, entries, &ctx.cancel)
                        .await
                        .map_err(|_| Error::Io { retryable: false })?;
                    ctx.set_index_result(report); // o el mecanismo de result de la Task
                    Ok(())
                })
            }),
        );
        Ok(handle)
    }
