# Volumes implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `Alt+F1` opens a drive picker that lists the host's volumes with their
free space, in both frontends. Closes #131.

**Architecture:** Enumeration is a HOST service (`norte-core::volumes`), not a
`Provider` method — a volume belongs to the machine, not to a path. The parser
is pure and carries most of the tests; the platform layer around it is thin.
The wire method is `host.volumes`, answered only to a `User` connection.

**Tech stack:** Rust, `rustix` or `libc` for `statvfs` (check which is already
in the tree before adding either), Fluent, no new dependency if avoidable.

**Spec:** `docs/superpowers/specs/2026-08-10-volumes-design.md`

- [ ] **Step 1: Write the failing parser tests**

In `linux.rs`. The samples are REAL `/proc/mounts` lines — copy them from the
machine you are on (`cat /proc/mounts`), do not invent the field order:

```rust
#[cfg(test)]
mod tests {
    use super::*;

    /// `/proc/mounts` escapes four characters in octal, and the unescape
    /// produces BYTES. A mount at `/media/USB de Ñico` — or at a name that is
    /// not UTF-8 at all — has to survive enumeration, the wire and the picker
    /// intact (rule 1). This is the line that decides whether it does.
    #[test]
    fn a_mount_point_with_escapes_comes_back_as_bytes() {
        let line = b"/dev/sdb1 /media/USB\\040de\\040Nico vfat rw,nosuid 0 0";
        let m = parse_line(line).expect("a well-formed line");
        assert_eq!(m.mount, b"/media/USB de Nico");
        assert_eq!(m.fs_type, "vfat");
        assert!(!m.read_only);
    }

    /// All four escapes, including the backslash itself — `\134` must not be
    /// unescaped into a character that then re-enters the unescape.
    #[test]
    fn every_octal_escape_is_understood_once() {
        let line = b"dev /a\\040b\\011c\\012d\\134e ext4 rw 0 0";
        let m = parse_line(line).unwrap();
        assert_eq!(m.mount, b"/a b\tc\nd\\e");
    }

    /// A name that is not UTF-8 is a name. It reaches `VPath` as bytes and
    /// nothing on the way turns it into a replacement character.
    #[test]
    fn a_non_utf8_mount_point_survives() {
        let line = b"/dev/sdc1 /media/\xff\xfe ext4 rw 0 0";
        let m = parse_line(line).unwrap();
        assert_eq!(m.mount, b"/media/\xff\xfe");
    }

    /// `ro` in the option list is the read-only flag; `rw` is not, and
    /// neither is an option that merely CONTAINS `ro` (`errors=remount-ro`
    /// is the one that catches a naive `contains`).
    #[test]
    fn read_only_is_an_option_not_a_substring() {
        let ro = parse_line(b"/dev/sda1 /mnt ext4 ro,noatime 0 0").unwrap();
        assert!(ro.read_only);
        let rw = parse_line(b"/dev/sda1 /mnt ext4 rw,errors=remount-ro 0 0").unwrap();
        assert!(!rw.read_only);
    }

    /// A line with too few fields is skipped, not a panic and not a
    /// half-filled Volume: /proc is a kernel interface and a short read
    /// during enumeration is a truncated last line, not a corrupt system.
    #[test]
    fn a_truncated_line_is_skipped() {
        assert!(parse_line(b"/dev/sda1 /mnt").is_none());
        assert!(parse_line(b"").is_none());
    }

    /// The filter is a declared list, so adding a hidden type is a visible
    /// diff and not a new branch somewhere.
    #[test]
    fn the_filter_hides_pseudo_filesystems_and_keeps_real_ones() {
        for t in ["proc", "sysfs", "cgroup2", "tmpfs", "squashfs", "overlay"] {
            assert!(is_pseudo(t), "{t} should be hidden");
        }
        for t in ["ext4", "btrfs", "xfs", "vfat", "ntfs3", "apfs", "nfs4", "cifs"] {
            assert!(!is_pseudo(t), "{t} is a filesystem a person mounts");
        }
    }
}
```

- [ ] **Step 3: Write the module**

`volumes/mod.rs` carries the public surface from the spec — `Volume`,
`VolumeKind`, `PSEUDO_FS` (the constant list), `is_pseudo`, and:

```rust
/// Every volume the host mounts. `include_pseudo` is the picker's
/// "show everything" toggle.
///
/// # Errors
/// Only a failure to read the platform's mount table. A mount whose space
/// query fails or times out is NOT an error: it comes back with `None` sizes.
pub async fn enumerate(include_pseudo: bool) -> Result<Vec<Volume>, Error>;
```

`linux.rs` carries `parse_line` (pure, `&[u8]` in, a raw mount record out),
the `/proc/mounts` read, and the space query.

Three things the implementation must get right, all argued in the spec:

- **Bytes throughout.** The mount point becomes a `VPath` via the same
  conversion the local provider uses; it never passes through `String`.
- **The space query carries a deadline.** `statvfs` on a hung NFS mount never
  returns, so it runs in `spawn_blocking` under a timeout, and the timeout
  yields `None` sizes rather than an error or a wait. Pick a deadline in the
  low hundreds of milliseconds and name the reasoning in a comment.
- **The kind.** `/sys/class/block/<dev>/removable` answers removable for a
  block device; a network `fs_type` (`nfs*`, `cifs`, `smb*`, `sshfs`,
  `fuse.sshfs`) answers `Network`; `is_pseudo` answers `Pseudo`; the rest is
  `Fixed`. Unknown stays `Unknown` rather than being guessed into `Fixed`.

**Files:**

- Modify: `crates/norte-core/src/backend.rs` (`Backend::volumes`, both modes)

- [ ] **Step 1: Proto first, with the guardian's rules in mind**

Additive method and result. `VolumeKind` gets `#[serde(other)]` on an `Unknown`
variant — the same shape `EntryKind::Other` and `TaskKind::Unknown` use — so a
kind added in N+1 degrades instead of breaking an older client. Bump the minor
version and shift the N-1 window as the previous bumps did.

The mount point is a `VPath` on the wire. Nothing in this feature carries a
mount point as a `String`; a golden must round-trip a non-UTF-8 one.

- [ ] **Step 2: Goldens and the version bump**

Add the new method to the frozen golden set. Follow what the last additive
method did (`policy.undo_session`, proto 0.12.0) — the pattern for the
window shift is in that commit.

- [ ] **Step 3: The handler is `User`-only**

The mount table names your disks, your servers and your removable media. An
agent under a scope does not need it. The handler checks the connection's
actor and answers an agent with `PolicyDenied`, using `DenyReason::rule_id()`'s
closed vocabulary — never the concrete rule.

Test both directions: a human connection gets the list, an agent connection
gets `PolicyDenied`. `agente_sin_scope_ve_policy_denied_humano_copia` in the
daemon tests is the shape to copy.

- [ ] **Step 4: `Backend::volumes` in both modes**

`Embedded` calls `norte_core::volumes::enumerate` directly; `Remote` calls the
new method. Same seam as the other pairs in `backend.rs`.

- [ ] **Step 5: Reviewers, then commit**

`protocol-guardian` is MANDATORY (`norte-proto` changed). `security-reviewer`
for the actor gate: ask it whether anything else in the response leaks host
information an agent could not otherwise get, and whether the embedded backend
(no daemon, no actor) is the hole in the gate.
