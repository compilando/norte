# D3 — `org.norte.markdown`: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a `.md` file opens in the viewer as styled text — headings, emphasis,
code, lists, quotes, links — in both frontends (K2 made the window paint
spans).

**Architecture:** a `previewer` guest (`norte-plugin` world) declaring exactly
`text/markdown`. `render.rs` folds the `pulldown-cmark` event stream into
lines of spans: headings get the theme role `title`, code the role `info`
(there are no content roles yet, deliberately), emphasis/strong/link URLs
carry fixed colours. Two host changes: `guess_mimetype` learns
`text/markdown`, and `resolve_previewer` prefers an exact declaration over a
glob so this plugin wins Markdown while syntect (`text/*`) keeps the rest.

**Spec:** `docs/superpowers/specs/2026-09-03-plugin-kit-and-demo-plugins-design.md`, section D3.
