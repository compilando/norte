# #55 tar.gz como scheme `tar+gz+…` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Navegar/leer `.tar.gz`/`.tgz` (el tar más común del mundo real) como scheme compuesto `tar+gz+file:///a.tgz/!/inner`, read-only, con cancelación y límites anti-bomba.

**Architecture (decisiones):**
1. **Gramática**: `tar+gz` entra como TOKEN COMPUESTO en `ARCHIVE_FORMATS` (proto). `scheme_format_prefix` pasa a longest-match contra la whitelist (hoy `split_once('+')` daría `tar` y dejaría un interior `gz+file` huérfano). NO se introduce un mecanismo general de capas (eso es #56/anidamiento, diferido); la capa gz es opaca dentro del formato. ADR nuevo lo fija.
2. **Índice**: gz es forward-only ⇒ `tar::Archive::entries()` (solo `Read`, sin `entries_with_seek`) sobre `flate2::read::MultiGzDecoder<ProviderReader>` (multi-member: tgz concatenados existen). Offsets del locator = stream DESCOMPRIMIDO: `Locator::Gz { offset: u64, size: u64 }`. La validación `offset+size <= container_len` del tar plano NO aplica (container_len es comprimido) — el truncamiento se detecta en el read (EOF prematuro del decoder ⇒ error, jamás datos silenciosamente cortos).
3. **Read**: forward-decode por lectura — decoder fresco sobre `ProviderReader` nuevo, descarta `offset+req_off` bytes, sirve `req_len` en chunks por el canal acotado (patrón zip existente: spawn_blocking + tx acotado + drop del stream = corte, regla 3). Coste O(descomprimido-hasta-offset) por read, DOCUMENTADO. Spool/restart-points = deuda con issue nueva.
4. **Anti-bomba**: `Limits.max_decompressed_bytes` (default 64 GiB) — presupuesto TOTAL descomprimido del pase de índice (gzip bomb = CPU infinita aunque la memoria sea streaming). Superarlo ⇒ mismo tratamiento que los demás límites del índice. El flag `cancel` se chequea por entrada (ya existe el patrón).
5. **flate2 = dep DIRECTA nueva de norte-vfs-archive** (ya transitiva vía zip/russh, misma versión 1.1.9, licencias ya en allowlist de deny) — justificación en la PR/commit (regla 8).

**Tech Stack:** norte-proto (vpath), norte-vfs-archive (+flate2), norte-core (engine map), norte-tui (extensiones), norte-cli, norte-testkit (gzip de fixtures en dev-tests, no en el crate).

**Método:** rama `feat/55-targz`. Subagentes NO commitean. Reviewers: **protocol-guardian OBLIGATORIO** (Task 2), rust-reviewer, encoding-auditor, security-reviewer (anti-bomba). `just ci` antes del merge.

```rust
pub const ARCHIVE_FORMATS: &[&str] = &["zip", "tar", "tar+gz"];

/// Prefijo de formato del scheme, LONGEST-MATCH contra la whitelist: un
/// token puede contener `+` (`tar+gz`), así que `split_once('+')` ya no
/// basta — `tar+gz+file` es formato `tar+gz` sobre `file`, no `tar` sobre
/// un `gz+file` huérfano (ADR NNNN).
fn scheme_format_prefix(scheme: &str) -> Option<&str> {
    ARCHIVE_FORMATS
        .iter()
        .filter(|f| {
            scheme.len() > f.len()
                && scheme.as_bytes()[f.len()] == b'+'
                && scheme.starts_with(*f)
        })
        .max_by_key(|f| f.len())
        .copied()
}
```

  (`archive_split`/`archive_compose` no cambian de cuerpo: ya operan sobre `format.len()+1` y la whitelist. VERIFICAR que la guardia `scheme_format_prefix(inner_scheme)` del split sigue rechazando interiores compuestos, y que compose rechaza outer compuesto.)

Locator::Gz { offset, .. } => {
    // Forward-decode: gz no es seekable — descarta hasta el offset y sirve
    // el tramo. O(descomprimido-hasta-offset) por read, documentado (ADR
    // NNNN); spool/restart-points = issue de deuda. Drop del stream = el
    // send falla = el hilo termina (regla 3).
    let reader = ProviderReader::new(
        tokio::runtime::Handle::current(),
        Arc::clone(&self.inner),
        aref.outer.clone(),
        cached.index.generation.1.unwrap_or(0),
    );
    let (tx, mut rx) = tokio::sync::mpsc::channel(4);
    let skip = offset + req_off;
    drop(tokio::task::spawn_blocking(move || {
        crate::targz_format::read_entry_gz(reader, skip, req_len, &tx);

    Ok(futures::stream::poll_fn(move |cx| rx.poll_recv(cx)).boxed())
