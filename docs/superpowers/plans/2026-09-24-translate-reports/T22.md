## Notes on translation approach

- `norte-vfs-local/src/confined.rs`'s `// SAFETY:` comments (justifying
  `unsafe` per hard rule 5, `openat2`/`O_NOFOLLOW` blocks) were translated
  preserving the exact same safety argument, never shortened.
- Hostile/encoding test data was left byte-for-byte unchanged where the
  bytes are the point of the test: CP437 (`CAF\x90.TXT`), NFD/Latin-1
  (`café`, `caf\xe9.txt`), lone surrogates, non-UTF-8 byte sequences, RTL
  and zip-slip/traversal payloads, and the full `norte-testkit::corpus`
  hostile name fixtures used across all three crates' contract/hostile
  test suites.
- Where translating ordinary (non-hostile) test content changed its byte
  length (e.g. `"hola"` (4) → `"hi"` (2), `"segundo!"` (8) →
  `"second!"` (7)), every dependent size/offset assertion in the same test
  was updated to match, and each affected test was re-run to confirm.
- Roughly 140 test functions were renamed from Spanish to English across
  the three crates' `tests/` directories and `#[cfg(test)] mod tests`
  blocks in `src/`; all were verified to keep passing via targeted
  `cargo test` runs per file before moving to the next.
