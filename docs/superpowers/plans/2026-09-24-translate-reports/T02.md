## 5. glossary — new terms proposed

- `huella (de nodo)` → **node fingerprint** (journal.rs; identifier not
  renamed, proposed for phase 2's glossary update alongside the rename).
- `rodeo` (as in `rename_por_rodeo`) → **detour**: renaming through a
  temporary intermediate name when a provider's rename cannot overwrite.
- `enterrar`/`enterrado` (trash as undo compensation, tracing fields) →
  **bury / buried**.
- `pieza`/`trozo` (archive entry / split chunk) → unified to **piece**
  (matches `file.combine`/`file.split`'s existing proto vocabulary).
- `informe` (a computed report struct) → **report** (matches
  `ArchivePackReportResult`, `ArchiveTestResult`).
- `hueco` (a missing numbered split piece) → **gap**.
- `vigencia` — not added since the identifier itself stayed Spanish
  (crosses files); if renamed in phase 2, **validity** is the natural term.
