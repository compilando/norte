## 2. cross-file literals

Kept, not translated:

- `"mem:///casa"` (`search.rs`, its doctest and tests): the conventional test
  root VPath used across dozens of files outside this task (`pane/tests.rs`,
  `navigation/{history,tree}.rs`, `gui-tauri/src/commands.rs`, etc.).
- `search.rs` test literal `"hola"` (`SearchForm::set_texto`/`texto`
  round-trip): it is the EXPECTED value of an `assert_eq!`.
- `shell.rs`'s `osc52` doctest: `osc52(b"hola")` compared against a hardcoded
  base64 literal — the input and the pinned expected output are coupled;
  translating one without recomputing the other would either break the test
  or silently stop testing what it claims to.
- `sort.rs` test fixtures that are also the EXPECTED value of an
  `assert_eq!`: `"f-sin"`, `"viejo"`, `"nuevo"`, `"medio"`, `"sin"`, `"uno"`,
  `"dos"`, `"raro"`, `"z-dir"`. (`"leeme"` and `"punto."` were NOT pinned by
  an assertion and were translated to `"readme"`/`"dot."`.)
- `sort.rs`/`search.rs` NFC/NFD test data `"año"`/`"año2"`: the accented
  bytes are the point of the test (Unicode normalization).
