## Other notes

- **Bug caught by running tests (not just cargo check), fixed in this pass**:
  translating Spanish test fixture strings to English changed their byte
  lengths in three places, and the hardcoded expected byte counts next to
  them were not updated at first pass:
  - `plugins/git-status/src/status.rs`: `the_racy_case_reads_and_compares_the_oid`
    used `b"hello"`/`b"other"` (5 bytes) against an index entry and `meta()`
    both declaring size `4` (from the original `"hola"`/`"otro"`, 4 bytes) —
    fixed by using 4-byte words (`"read"`/`"seen"`) instead of translating
    literally. Also normalized three other tests in the same file that had
    `"hello"` (5 bytes) sitting next to an untouched `meta(4, …)` — harmless
    there (content is never read on those paths) but misleading; changed to
    a real 4-byte word (`"text"`) or a real 6-byte word (`"growth"`) to match.
  - `crates/norte-vfs-sftp/tests/hostile.rs`:
    `resume_over_sftp_resumes` asserted `already == 4` after writing
    `b"hello"` (5 bytes); fixed to `5`.

  the plan's "cargo check only" gate were the only check — flagging in case
