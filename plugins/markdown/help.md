Shows a Markdown file in the viewer as styled text instead of raw markup:
headings in the theme's title colour, emphasis and strong in their own
colours, inline and fenced code in the info colour with the fences dropped,
lists as bullets, quotes with a bar, links as `text (url)`.

It handles `.md` and `.markdown` files (`text/markdown`) and nothing else.
The viewer's raw view is one key away, as always.
