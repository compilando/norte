Puts a small badge next to each entry saying what kind of file it is: code,
script, document, image, audio, video, archive, configuration, and a few
names that mean something on their own (`Makefile`, `Cargo.toml`,
`.gitignore`, `Dockerfile`, `LICENSE`, `README`).

It decides from the name alone. It never opens the file, never learns where
you are, and never sees whether an entry is a directory.

The `style` setting switches between emoji and plain ASCII glyphs, for
terminals whose font has no emoji.
