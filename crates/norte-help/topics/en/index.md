norte is an orthodox file manager. Two panes, the keyboard first, and one set
of commands whether the files are on this machine, on an SSH host, in an
S3-compatible bucket, or inside a `.zip`.

That last part is the whole idea. A backend is not a mode you enter and leave;
it is only what a pane happens to be showing. Copying out of an archive into a
bucket is the same two keys as copying between two local directories.
